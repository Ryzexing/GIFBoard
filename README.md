# GIFBoard
GIFboard is a BetterDiscord plugin for its own GIF library. It adds a tab to Discord's standard GIF picker and lets you save GIFs to folders, search them, and send them to chat.
(Create folders to sort your GIFs)
(The interface language depends on the discord language)
