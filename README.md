# GIFboard+

GIFboard+ is a personal GIF library built directly into Discord's GIF picker. Save GIFs into folders, find them using search, and send them in chat.

## Installation

1. Place `GIFboard+.plugin.js` into your BetterDiscord plugins folder.
2. Open **User Settings → BetterDiscord → Plugins** and enable **GIFboard+**.
3. Open Discord's GIF picker and select the **My GIFs** tab.

## Main Features

- **Folders:** Click `+` in the sidebar to create a folder. Right-click a folder to rename or delete it.
- **Save GIFs from Discord:** Right-click a GIF in the default picker and select a folder. The same GIF can be saved to multiple folders.
- **Local GIFs:** Drag and drop a `.gif` file from your computer directly onto a folder in your library. The plugin validates the file format and skips duplicates.
- **Search:** Use the search bar to find GIFs across your saved folders.
- **Sending GIFs:** Click a GIF in your library to send it to the currently open chat. If you have a message selected to reply to, the GIF will be sent as a reply.
- **Favorites:** Enable "Add to Favorites when adding to a folder" in the settings to automatically add GIFs to Discord Favorites, whenever possible.
- **Window Size and Position:** Drag the window by its header to move it. Resize it using the edges or corners. The folder sidebar width can be adjusted by dragging the divider. Window position and dimensions are saved automatically.
- **Default Picker:** When you first open the library, the default GIF picker is hidden. You can reopen it using the GIF button next to the message input field, while keeping your library accessible.
- **Backup:** **Export** downloads your library as a JSON file. **Import** merges a backup with your current library, skipping duplicates.

The library is stored locally through BetterDiscord. Local GIFs can be viewed in the library, but sending these files is not yet supported.

# GIFboard+

GIFboard+ — личная библиотека GIF внутри GIF-пикера Discord. Сохраняйте GIF по папкам, находите их поиском и отправляйте в чат.

## Установка

1. Поместите `GIFboard+.plugin.js` в папку плагинов BetterDiscord.
2. Откройте **Настройки пользователя → BetterDiscord → Plugins** и включите **GIFboard+**.
3. Откройте GIF-пикер Discord и выберите вкладку **My GIFs** («Мои GIF»).

## Основные функции

- **Папки:** нажмите `+` в боковой панели, чтобы создать папку. Нажмите на папку правой кнопкой, чтобы переименовать или удалить её.
- **Сохранение GIF из Discord:** нажмите правой кнопкой на GIF в стандартном пикере и выберите папку. Один GIF можно сохранить в несколько папок.
- **Локальные GIF:** перетащите файл `.gif` с компьютера прямо на нужную папку в библиотеке. Плагин проверит формат и пропустит дубликаты.
- **Поиск:** используйте строку поиска, чтобы найти GIF в сохранённых папках.
- **Отправка:** нажмите на GIF в библиотеке, чтобы отправить его в открытый чат. Если выбрано сообщение для ответа, GIF отправится ответом.
- **Избранное:** в настройках включите «В избранное при добавлении в папку», чтобы GIF автоматически добавлялся в избранное Discord, если это возможно.
- **Размер и положение:** перемещайте окно за заголовок; меняйте его размер за края или углы. Ширину панели папок можно изменить перетаскиванием разделителя. Положение и размеры сохраняются.
- **Стандартный пикер:** при первом открытии библиотеки стандартный пикер скрывается. Его можно открыть кнопкой GIF у поля сообщения; библиотека при этом остаётся доступной.
- **Резервная копия:** **Export** скачивает библиотеку в JSON. **Import** объединяет резервную копию с текущей, пропуская дубликаты.

Библиотека хранится локально через BetterDiscord. Локальные GIF можно просматривать в библиотеке, но отправка таких файлов пока не поддерживается.
